# GSDD 加载

为当前任务产出 SSOT 任务简报。核心纪律：**索引先行、按需取段**，不为一个任务读整个 ssot/。没有 ssot/ 的项目 → 提示先跑 `/gsdd-init`。

## 三步取段法

1. **路由器**：全文读 `ssot/README.md`（它很小，且是唯一入口）。
2. **定位**：对 L0/L1/L2 各文件——
   - 文件 ≤ 300 行（README 头部可调此阈值）→ 可全文读。
   - 超过阈值 → **禁止全文**。用 grep 按编号/关键词命中索引行与小节标题，再按行号只取命中段落；需要浏览面时只读其 `## 索引` 段。
3. **取段**：只取任务相关条目的全文（验收项、术语口径、design 小节、剧本步骤）。

## 任务简报（≤ 2000 token）

以任务描述（args）为输入，简报只装四样：

1. 相关验收项**全文**（A 编号 + 原文）。
2. 涉及的术语唯一口径（只列术语与定义，不搬运 design 正文）。
3. 波及剧本的相关步骤（只列步骤与编号）。
4. 本任务禁止事项：不新增验收项/标准；发现规范缺口 → 建议 `/gsdd-change` 提案，不停工等答复，先按现行 SSOT 干活。

简报留在对话里，不落盘（ssot/ 与 evidence/ 都不放）。
