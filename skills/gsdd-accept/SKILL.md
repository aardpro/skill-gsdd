# GSDD 验收

输入（args）：验收项编号列表、剧本名，或缺省=全量。AI 只执行验收并产出证据，无权自造或改写验收项。

## 流程

1. **定位**：索引先行、按需取段读相关剧本与验收项（大文件走索引，不全文扫）。
2. **执行**：沿剧本逐步走查。能自动跑的跑 tests/（测试必须引用验收项编号）；自动不覆盖的步骤按剧本手工验证并记录。不跳步、不带病继续。
3. **失败**：停在该步，报告到编号粒度（哪个 A 号、哪一步、期望 vs 实际）。
4. **证据**：每步结论落 `evidence/<YYYY-MM-DD>-<剧本名或编号>/`（日志、截图、测试输出），并给出「编号 → 证据路径」映射。证据不进 ssot/。
5. **冲突仲裁**：测试断言与 acceptance 冲突 → 错的是测试或实现，回 SSOT 仲裁；走查中发现规范缺口 → 建议 `/gsdd-change` 提案，不自行改。

## TDD 收窄口径

业务规则必须测；UI 文案与样式不进自动化；快速冒烟自动跑，慢测试手动/定期触发。
